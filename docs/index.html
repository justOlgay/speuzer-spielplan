Speuzer – Spielpläne abonnieren

Saison 2026/27 · Quelle: DFBnet · einmal abonnieren, dann automatisch aktuell

So funktioniert das Abo

iPhone / iPad: auf „Im Kalender abonnieren" tippen und bestätigen. Unter Einstellungen → Apps → Kalender → Accounts → Abonnierte Kalender kann man das Aktualisierungs­intervall auf „Jede Stunde" stellen.

Android / Google Kalender: „Link kopieren", dann am Rechner auf calendar.google.com → Weitere Kalender → Per URL. Google aktualisiert abonnierte Kalender nur alle paar Stunden, im Extremfall dauert es bis zu 72 Stunden.

Outlook: Kalender hinzufügen → Aus dem Internet abonnieren → Link einfügen.

Wichtig: kurzfristige Absagen kommen weiter per Push in der Vereins-App – der Kalender ist für die Planung, nicht für Last-Minute-Infos.

Spieltermine automatisch erzeugt aus dem DFBnet-Spielplan. Verlegungen werden im bestehenden Termin aktualisiert, es entstehen keine Doppel-Einträge. Fragen: Jugendleitung.
